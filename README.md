# AFM 智能操作助手

中心有一台 AFM，操作手册几百页，新同学上手时翻不到对应内容，培训课听完也容易忘。这个项目就是想把这些文档变成一个能对话的助手，直接问就行。

## 我主要想解决的问题

**查得快**：输入问题直接拿到操作步骤，不用翻手册找半天。支持连续追问，比如先问"怎么开机"，再问"开机后怎么装探针"，上下文不会断。

**图片也能查**：拍一张仪器界面的照片传上去，系统会自动识别文字再去知识库里找对应内容。

**安全提醒优先**：这是比较看重的一点。AFM 操作里有几类操作如果搞错会直接损坏仪器——

- **换针/更换探针**：探针很脆弱，安装不到位或操作不当会损坏探针甚至压坏样品台。只要问到换针相关的问题，系统会先提醒"请联系老师"，然后再给出操作参考，最后附上免责声明。
- **调焦/聚焦/进针**：调焦时如果看不清探针和样品就点进针，大概率撞针。恒高模式用错场景也会直接刮花样品。这类问题同样会先弹警示。

这些安全规则写在 `quick_answers.json` 里，加一条 JSON 就能新增一个安全提示规则。未来要给某个操作加提醒，改一下配置文件即可。

## 快速开始

```bash
pip install -r requirements.txt
streamlit run afm_rag_streamlit_image.py
```

浏览器打开 `http://localhost:8501`。

左侧边栏填入 API Key 可以启用大模型优化回答，不填也能用，直接返回检索到的原文。

## 知识库

知识库是 JSON 格式，每条文档包含标题、来源、正文和标签：

```json
{
  "id": "唯一ID",
  "source": "来源",
  "title": "标题",
  "content": "内容正文",
  "tags": ["标签1", "标签2"]
}
```

把自己的文档放到 `shujuku/` 目录下，重启就自动加载。也可以在网页里直接追加。

## 安全规则

`quick_answers.json` 目前配了两条规则，换针和调焦进针，都是命中关键词后先给警示、再给正常回答。想加新的安全提示，往数组里追加一条：

```json
{
  "mode": "prepend",
  "topic": "激光安全",
  "keywords": ["开激光", "laser on"],
  "keyword_groups": [["激光", "开启"]]
}
```

警示文案不写的话会根据 topic 自动生成，想自定义也可以手动写 `warning` 和 `footer`。

## 后续计划

现在这个版本是一个问答助手，用户问什么它答什么。更长远的目标是把它变成一个能自主完成实验的 Agent——

用户只需要说"帮我扫这个样品，轻敲模式，5 微米，给粗糙度报告"，Agent 自己完成整个流程：

1. **自动寻样**：通过摄像头或低分辨率预扫描找到样品位置，评估表面平整度决定是否需要换区域
2. **自动配置参数**：根据样品类型和用户要求，选择扫描模式、分辨率、扫描范围、扫描速度，不需要手动一个个填
3. **自动执行扫描**：调用仪器控制接口开始扫描，过程中实时监控反馈信号
4. **实时微调**：如果扫描过程中发现图像有条纹、漂移、信号太弱等问题，自动调整增益、扫描速度或 Setpoint，不用人工干预
5. **自动分析结果**：扫描完成后自动算粗糙度、颗粒统计、高度分布等，直接生成报告

这里面每一步都有不少技术挑战：自动寻样需要图像识别 + 平整度评估算法，参数选择需要把经验规则结构化或者用历史数据训练，实时微调需要建立反馈控制模型，仪器控制需要对接厂商 SDK 或自己写驱动层。

我目前在代码里已经预留了一个指令解析的接口，用户输入自然语言指令后可以解析成结构化的 JSON 参数表（扫描模式、分辨率、范围、分析任务等），这是走向自主工作流的第一步。
